# Personal Expense & Budget Tracker (MERN Stack)

A full-stack personal finance web application built with MongoDB, Express.js, React (Vite), and Node.js.

## Features
- Add income and expense transactions with category and date
- Live summary dashboard (Total Balance, Total Income, Total Expense)
- Filter transactions by type (`All`, `Income`, `Expense`) and category
- Delete transactions with instant state and database sync
